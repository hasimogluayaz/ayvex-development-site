## Logo Placement

The header logo is loaded from:

- `./assets/ayvex-logo-light.png`

To activate your logo:

1. Create an `assets` folder (if not present).
2. Place your preferred logo image as `ayvex-logo-light.png`.
3. Refresh the page.

If you also want a footer logo later, we can add `ayvex-logo-dark.png` and use both versions.
